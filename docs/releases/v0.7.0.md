# v0.7.0 Release Notes

**Release Date:** 2026-08-16

VisionStudio v0.7.0 closes `INIT-VISIONSTUDIO-011` (Portfolio WIP Management), built directly off a gap found while manually closing four other initiatives earlier this session: `INIT-AGENTPROTOCOLS-001` sat at `executing` with all 5 RMIs completed across 3 repositories, and finding that required hand cross-referencing RMI status against real git state in every referenced repo. This release automates that check and adds a way to see the whole portfolio's WIP at a glance.

Like v0.6.0, this release is prepared and documented but **not yet tagged** — same convention: committed and pushed is enough to close an initiative, tagging is a separate, later, batched action.

## Highlights

- **`initiative sweep`** — finds initiatives whose RMI completion has outrun their recorded lifecycle status, verified against real per-repo git state across every repository an initiative's RMIs touch, not just its home repo
- **Dashboard By Status view** — the initiative portfolio grouped into pipeline-ordered columns (`proposed` through `cancelled`), for managing WIP at a glance alongside the existing By Program grouping

## `initiative sweep`

```bash
visionstudio initiative sweep [--format json]
```

Lists non-terminal initiatives (`proposed`/`planned`/`executing`) where every RMI is `completed`. For each candidate, resolves every distinct repository referenced by its RMIs and reports local git state — clean and in sync, dirty, unpushed commits, behind upstream, or not found/not registered locally — using cached refs only (no network fetch), the same best-effort posture as `registry doctor`.

`sweep` is report-only. It never calls `initiative transition` or `release record` itself, and it cannot verify that a `completed` RMI's shipped code actually matches its written description — that stayed a human/agent judgment call in this session's manual audits, and it stays one here. Running it immediately surfaced two more real candidates: `INIT-VISIONSTUDIO-003` (25 RMIs, never advanced past `proposed`) and `INIT-VISIONSTUDIO-007` (its last RMI completed earlier this session) — left for separate review, not closed as part of this release.

## Dashboard By Status View

A new `/status` route and Sidebar entry (📊 By Status, above the program list) group every visible initiative into columns by lifecycle status. Reuses the existing `/api/execution` response — no new endpoint. `StatusBadge` gained colors for `delivery_complete`/`releasing`/`released`/`closed`, which previously all fell back to `proposed`'s gray and would have made a status-grouped view hard to scan.

## Documentation

PRD/ROADMAP added for `INIT-VISIONSTUDIO-011` (PRD+ROADMAP-only, same scope-note pattern as `INIT-VISIONSTUDIO-010` — reversible internal tooling). `sweep` and the Status view documented in the dashboard guide and tour. `CLAUDE.md` gained a convention entry codifying "closing an initiative doesn't require a git tag" — the pattern used four times earlier this session before this tooling existed to help find candidates for it.
