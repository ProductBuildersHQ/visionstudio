# v0.8.0 Release Notes

**Release Date:** 2026-08-16

VisionStudio v0.8.0 closes out three acceptance-testing follow-ups found while actually using v0.7.0's By Status view and progress bars live — none anticipated by `INIT-VISIONSTUDIO-011`'s original PRD/ROADMAP, all folded back into it as a fourth phase before re-closing. Like v0.6.0/v0.7.0, this release is prepared and documented but **not yet tagged**.

## Highlights

- **Cancelled work is visually distinct** — progress bars show cancelled RMIs in red instead of blending into the "not done yet" gray, and turn green (not blue) once completed + cancelled account for the whole bar, since nothing is actually still in flight at that point
- **`visionstudio app restart`** — replaces a stale UI+API server (e.g. one still serving an old binary after a rebuild) in place, without hunting down and killing a PID by hand

## What Happened

Verifying the By Status view against real data (`INIT-OMNIAGENT-002`, 82% completed / 18% cancelled) surfaced two things the original spec never considered:

1. The progress bar had no way to show "cancelled," so a fully-resolved initiative with some cancelled scope looked identical to one still genuinely in progress — same blue bar, same gray tail.
2. Checking the fix required manually finding and killing a background UI process serving an old binary — there was no CLI command to just replace it.

Both are now fixed:

- `cancelledProgress` was added to `APIInitiative`/`APIPhase` (both dual-struct layers — `cmd/visionstudio/api.go` and `pkg/apitypes/types.go`, regenerated schema/Zod/TS) and `ProgressBar` gained a red segment sized off it, wired through every live consumer: initiative tiles, the by-program aggregate bar, the By Status board, and phase bars (`ad47edd`)
- `ProgressBar` colors the completed segment green whenever completed + cancelled reach 100% — nothing left pending — instead of the blue used for real remaining work (`11ac490`)
- `visionstudio app restart` tracks the UI+API server's own PID (`ui.pid`, mirroring Dolt's existing `server.pid`) and stops-then-starts it in one command, leaving the database alone if it's already running (`d0e0b5d`)

## Documentation

`INIT-VISIONSTUDIO-011`'s ROADMAP.md gained a fourth phase, "Acceptance Testing Follow-ups," documenting all three RMIs with the gap that prompted each and the commit that closed it — the same level of detail as the initiative's original scope, so the historical record shows what was actually delivered, not just what was originally planned.

## What's Next
