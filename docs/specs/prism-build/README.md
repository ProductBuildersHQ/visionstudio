# prism-build specifications

These documents are the specification set of the `prism-build` repository
(PRISM Control), which has been folded into VisionStudio and archived. They
are kept here unchanged as the design record for:

- `INIT-PRISMCONTROL-001` — PRD, TRD, and PLAN
- `INIT-PRISMCONTROL-002` — `ROADMAP-CONTEXT-ASSEMBLY.md` (and the TRD)
- `INIT-TOKENATTRIB-001` — `ROADMAP-TOKEN-ATTRIBUTION.md` (and the TRD)

They describe the `prismctl` command-line tool, whose code now lives in this
repository as the `visionstudio` binary; read command names and flags in them
as historical and check `visionstudio --help` for the current ones.

The plan for `INIT-PRISMCONTROL-003`, which is still in progress, is in
[`../initiatives/INIT-PRISMCONTROL-003/`](../initiatives/INIT-PRISMCONTROL-003/PLAN.md).

The original files remain in the archived repository at
<https://github.com/ProductBuildersHQ/prism-build/tree/main/docs/specs>.
